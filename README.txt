Т.Эрдэнэдэлгэрт зориулсан дурсамжийн сайт
========================================
Ажиллуулах:
1. ZIP файлыг бүтнээр нь задлана.
2. index.html дээр хоёр дарж нээнэ.
3. Эхлэх товч дарахад music.mp3 тоглож эхэлнэ.
4. Зургууд photos хавтсанд, хөгжим music.mp3 файлд байна.

Захидлыг өөрчлөх:
index.html дотор "Хайрт эгч Т.Эрдэнэдэлгэртээ," гэсэн хэсгийг хайж, өөрийн үгээр солино.

GitHub Pages:
1. GitHub дээр шинэ repository үүсгэнэ.
2. ZIP-ийн задласан БҮХ агуулгыг repository-ийн үндсэн түвшинд upload хийнэ.
3. Settings -> Pages -> Deploy from a branch -> main / root -> Save.
4. Хэдэн минутын дараа GitHub Pages линк үүснэ.

Анхаарах нь: GitHub Pages нь нийтэд нээлттэй. Хувийн зургуудыг зөвхөн линк мэддэг хүн нээх боломжтой гэсэн үг биш. Нууцлал шаардлагатай бол private hosting / authentication хэрэглэнэ.
